An emulator of a computer built around the Intel 80386, with basic hardware to be able to boot systems.

I'm simply a big fan of this CPU. I wanted to buy a whole computer to be able to live the experience of the '85s, but (surprisingly) it's neither cheap as a whole nor easy to buy. Someday I'll have that CPU, a good relic.

I'm not using QEMU because I want to shoot myself in the foot and use a CPU that actually runs at 33 MHz, with no JIT, and period-correct motherboards and integrated devices.

Are there alternatives? Yes, ones that are better than anything I'll ever make.

I just felt like doing this. No reason, no goal, just messing around with it. I hope you understand.
